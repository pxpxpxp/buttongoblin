From editor to MiSTer

  1. Install the Mini launcher package, then export your layout here. Wait for Update All to finish and run Scripts/ButtonGoblin_Mini_Disable.sh before copying files.
  2. Extract the export onto /media/fat , replacing the matching all six buttons*.conf files and icons.
  3. Run Scripts/ButtonGoblin_Mini_Enable.sh . Use ButtonGoblin_Mini_Enable.sh if the launcher is stopped.

Paths are on your MiSTer, not this computer. Relative paths start at /media/fat . This editor prepares files; it does not execute scripts or connect to the deck.

Scripts run through /bin/sh without arguments, one at a time, with a 60-second limit. Update All uses Bash with a one-hour limit and the installed updater; check its progress using the updater log over SSH. A busy script key shows its error icon. Use .mgl to launch a specific game.
