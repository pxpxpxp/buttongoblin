Download Mini v1.0.5 ZIP · Installation and source · 15-key guide

Physical key 4 on Home runs Update All. Key 6 cycles through all six pages; Shortcuts includes Back to Home. Tap Home’s brightness key for five ascending levels, or hold it one second to jump to Navigation. Keyboard shortcuts turn green while held. Page 6 adds Y and N for the active MiSTer screen; these keyboard events do not feed the background Update All process, which runs with non-interactive input.

Use both decks

Download the Dual v1.0.3 bundle, copy its complete Scripts contents, and run StreamDeck_Both_Enable.sh. The Mini and 15-key MK.2 have separate configurations, services and brightness.

Install Mini only

When upgrading Mini v1.0.0/v1.0.1, first run the old StreamDeck_Disable.sh. For later Mini versions, use StreamDeck_Mini_Disable.sh. Back up custom settings. Copy this Mini package’s Scripts contents, including hidden .config, into /media/fat/Scripts; run StreamDeck_Mini_Enable.sh. Install Update All separately at Scripts/update_all.sh.

This is a Mini-specific build. The 15-key editor and MK.2 artwork exports do not apply. The Mini build is host-tested and cross-compiled; physical Mini orientation, brightness, and USB playback need your hardware check.
